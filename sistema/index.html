Clique no botão verde **Commit changes...** para salvar o arquivo na pasta `sistema`. Se no futuro você gerar um novo build (`npm run build`), os nomes dos arquivos CSS e JS vão mudar (os códigos depois do hífen mudam). Nesses casos, basta atualizar os nomes no `index.html`. Para verificar se funcionou, acesse `https://quriosite.com/sistema` no seu navegador e confirme se a aplicação carregou corretamente.
